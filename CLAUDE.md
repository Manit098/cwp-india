This is the CodeWithPurpose India website repository. It uses Next.js, React, TypeScript, and Tailwind CSS. Keep edits small, clean, and aligned with the existing structure.

- Use Node.js 24 LTS.
- Prefer existing patterns already used in `app/` and `README.md`.
- Do not add unnecessary tooling or dependencies.
- Keep docs updated when setup or workflow changes.
