# Contributing

Thanks for helping improve CodeWithPurpose India.

## Quick start

- Use Node.js 24 LTS
- Run `npm install`
- Start the app with `npm run dev`

## Before opening a pull request

1. Create a branch for your change.
2. Keep the scope focused and avoid unrelated edits.
3. Run the project checks:
   - `npm run check`
4. Make sure the PR is easy to review.

## Coding guidelines

- Follow the existing code style and structure.
- Do not make unrelated formatting or refactor changes.
- Write clear commit messages.
- Update documentation if your change affects setup, usage, or contributor workflow.

## Issues and pull requests

- For bugs, include steps to reproduce, expected behavior, and actual behavior.
- For feature ideas, explain the problem and why the change would help.
- Keep discussions respectful, constructive, and focused on the project.

## Review process

Maintainers may request changes before merging. Please respond politely and update your work based on the feedback.
